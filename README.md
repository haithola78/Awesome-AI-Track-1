# 🧠 AI & Machine Learning Track 1: Study AI as a Field

This repository tracks my progress through Track 1 of the [Awesome AI Learning Guide by h9-tec](https://github.com/h9-tec/Awesome_ai_learning). 

**The Goal:** Go from zero to someone who can build, train, evaluate, and ship models.
**Time Commitment:** ~10 hours/week.

---

## 🟢 Stage 0: Foundations (Math + Code + Intuition) (Weeks 1-3)
**Exit Criteria:** I can write basic Python, know what a matrix multiplication and a gradient are, and can explain "training a model" to a friend.

### 📚 Original Repository Resources
- [ ] **Course:** [Elements of AI (Univ. of Helsinki)](https://www.elementsofai.com/) - The cleanest conceptual intro to AI.
- [ ] **Interactive:** [Kaggle Learn](https://www.kaggle.com/learn) - Bite-size Python, Pandas, and intro ML.
- [ ] **Book:** *Mathematics for Machine Learning* (Deisenroth, Faisal, Ong) - Free PDF.

### 📺 Recommended YouTube Alternatives (Visual Learning)
- [ ] **Math Visualized:** [3Blue1Brown - Neural Networks & Linear Algebra](https://www.youtube.com/playlist?list=PLZHQObOWTQDNU6R1_67000Dx_ZCJB-3pi) (This is also recommended by the repo itself!)
- [ ] **Python/Pandas Visualized:** [Keith Galli - Pandas Data Science Tutorial](https://www.youtube.com/watch?v=vmEHCJofslg) - Watch this if Kaggle Learn's text-based approach gets boring.
- [ ] **Stats Visualized:** [StatQuest with Josh Starmer](https://www.youtube.com/@statquest) - The repo specifically mentions him. Watch his videos on probability, variance, and distributions.

---

## 🟡 Stage 1: Classical Machine Learning (Weeks 4-8)
**Exit Criteria:** I have trained several models myself, understand overfitting, train/test splits, and evaluation metrics, and have at least one Kaggle notebook I'm proud of.

### 📚 Original Repository Resources
- [ ] **Course:** [Andrew Ng Machine Learning Specialization](https://www.coursera.org/specializations/machine-learning-introduction) (Coursera).
- [ ] **Practice:** Enter a beginner Kaggle competition (Titanic or House Prices). Read winning solutions and iterate.

### 📺 Recommended YouTube Alternatives (Visual Learning)
- [ ] **Andrew Ng on YouTube:** [Stanford CS229: Machine Learning (Full Course)](https://www.youtube.com/playlist?list=PLoROMvodv4rMiGQp3WXShtMGgzqpfVfbU) - If you don't want to use Coursera, watch his official university lectures here.
- [ ] **Algorithms Visualized:** [StatQuest - Machine Learning Playlist](https://www.youtube.com/playlist?list=PLblh5JKOoLUICTaGLRoHQDuEAq44JND60) - Perfect companion when an algorithm (like Random Forests or Gradient Boosting) refuses to click.
- [ ] **Coding Walkthrough:** [Ken Jee - Titanic Project Walkthrough](https://www.youtube.com/watch?v=I3FBJdiExcg) - A visual step-by-step on how to actually submit your first Kaggle competition.

## 🔴 Stage 2: Deep Learning & Frameworks (Weeks 9-12)
**Exit Criteria:** I can build and train a CNN and a small transformer in PyTorch, and explain backpropagation without hand-waving.

### 📚 Original Repository Resources
*The repo suggests picking ONE path as your spine:*
- [ ] **Path A (Top-Down):** [fast.ai](https://course.fast.ai/) (Build things first, understand later).
- [ ] **Path B (Bottom-Up):** Andrew Ng's Deep Learning Specialization (Understand first, build later).
- [ ] **Book:** *Neural Networks and Deep Learning* by Michael Nielsen.

### 📺 Recommended YouTube Alternatives (Visual Learning)
- [ ] **Fast.ai on YouTube:** [Jeremy Howard's fast.ai 2022/2023 Playlist](https://www.youtube.com/playlist?list=PLkVbIsAWN2ls1pYEEs0vEnP6Lh0d0Yd6v) - The exact fast.ai course, but directly on YouTube.
- [ ] **PyTorch Framework:** [Daniel Bourke - PyTorch in 10 Hours](https://www.youtube.com/watch?v=V_xro1bcAuA) - If you struggle with the code in Ng's or fast.ai's courses, watch this to visually learn the PyTorch syntax.

## 🔥 Stage 3+: LLMs, Transformers & Advanced Systems (Post-Week 12)
**Exit Criteria:** I understand how Large Language Models work under the hood, how to apply RAG, and when to use AI Agents.

### 📚 Original Repository Resources
- [ ] **Course:** Andrej Karpathy's "Zero to Hero". *(The repo notes: "Let it hurt a little. That pain is the field entering your brain.")*
- [ ] **Reference Book:** *Understanding Deep Learning* by Simon J.D. Prince (The modern theory book).
- [ ] **Specialty Courses:** Hugging Face Audio Course & Deep RL Course.
- [ ] **Reading:** Anthropic's "Building Effective Agents" & Nathan Lambert's writings on RLHF.

### 📺 Recommended YouTube Alternatives (Visual Learning)
- [ ] **Karpathy on YouTube:** [Andrej Karpathy - Neural Networks: Zero to Hero](https://www.youtube.com/playlist?list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ) - The exact resource recommended, available entirely on YouTube. Start with his "Micrograd" and "Let's build GPT" videos.
- [ ] **Transformers Visualized:** [Umar Jamil - Attention Is All You Need Explained](https://www.youtube.com/watch?v=bCz4OMemCcA) - A highly visual walkthrough of the paper that started the Generative AI boom.
- [ ] **Hugging Face Visualized:** [Hugging Face Official Channel](https://www.youtube.com/c/huggingface) - Watch their NLP and Audio course playlists directly on YouTube.
